CORDIC Accelerator

A custom hardware accelerator implementing the Coordinate Rotation Digital Computer (CORDIC) algorithm using Verilog HDL.

Language Verilog HDL
Architecture Iterative CORDIC
Platform Tiny Tapeout

01. Architecture

CORDIC is an iterative mathematical algorithm that uses additions, subtractions, and bit shifts to perform operations such as trigonometric calculations.

Rotation Mode

The accelerator uses successive iterations to rotate an initial vector towards a target angle. Each iteration adjusts the vector and reduces the remaining angular error. 

x_next = x - (y >>> i)
y_next = y + (x >>> i)
z_next = z - atan(2^-i)

Hardware Components

  • Rotation module
  • Angle lookup table
  • Control logic
  • Iteration counter
  • Input/output interface

02. Hardware Interface

The top-level module manages communication between the external interface and the internal CORDIC implementation.

Top-Level Signals

Signal Direction Description
clk Input System clock
rst_n Input Active-low reset
start Input Starts computation
x_pos Output Final X coordinate
y_pos Output Final Y coordinate
step Output Current iteration
busy Output Indicates active computation

03. Implementation

The accelerator is implemented using modular Verilog design, separating the computational logic from the control and lookup logic.

Design Considerations

  • Fixed-point arithmetic
  • Signed binary representation
  • Sequential iteration logic
  • Clock synchronization
  • Hardware resource utilization

04. Simulation & Testing

Before hardware fabrication, the RTL design is validated through simulation using Icarus Verilog.

Compilation

iverilog -g2012 -o rotation_sim \
RTL/top.v \
RTL/rotation.v \
RTL/anglelookup.v \
testbench/rotation_tb.v

Run Simulation

vvp rotation_sim

Testing Objectives

  • Verify correct rotation calculations
  • Validate signed arithmetic
  • Check reset functionality
  • Verify iteration completion
  • Test busy and start signals
