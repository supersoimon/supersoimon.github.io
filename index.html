CORDIC Accelerator

Hardware implementation of the Coordinate Rotation Digital Computer algorithm using Verilog.

This project explores the implementation of a mathematical accelerator in digital hardware. The objective is to design, simulate, and eventually fabricate a custom CORDIC accelerator using the Tiny Tapeout platform.

The project is written in Verilog HDL and uses an iterative architecture to perform vector rotations through a sequence of additions, subtractions, and bit shifts.

Background

The Coordinate Rotation Digital Computer (CORDIC) algorithm is a method of performing mathematical operations using relatively simple hardware. Rather than relying on multiplication or complex arithmetic units, CORDIC performs calculations through repeated shifts and additions.

This makes it particularly useful for hardware applications where minimizing resource utilization is important.

Architecture

The accelerator implements CORDIC in rotation mode. An input vector is progressively rotated through a series of iterations, with each iteration applying a smaller angular adjustment.

Iteration equations

x_next = x - (y >>> i)
y_next = y + (x >>> i)
z_next = z - atan(2^-i)

Each iteration updates the vector coordinates and the remaining angular displacement. The angle values are retrieved from a lookup table.

Module structure

The design is separated into three primary modules:

  • top.v — top-level module and control interface.
  • rotation.v — iterative CORDIC computation.
  • anglelookup.v — lookup table for iteration angles.

Implementation

The RTL is implemented using sequential Verilog. A clock-driven process manages the iteration counter and updates the vector coordinates at each clock cycle.

The design uses signed fixed-point arithmetic to represent the vector coordinates and angular values. Arithmetic right shifts are used to perform the divisions required by each iteration.

Hardware Interface

The top-level design exposes an interface for controlling the accelerator and retrieving its results.

Signal Direction Description
clk Input System clock
rst_n Input Active-low reset
start Input Begins computation
x_pos Output Final X coordinate
y_pos Output Final Y coordinate
step Output Current iteration
busy Output Computation status

Testing

The RTL is tested using Icarus Verilog. A testbench provides input signals, controls the clock and reset, and monitors the accelerator's outputs.

Compilation

iverilog -g2012 -o rotation_sim \
RTL/top.v \
RTL/rotation.v \
RTL/anglelookup.v \
testbench/rotation_tb.v

Simulation

vvp rotation_sim

Testing focuses on verifying the mathematical output, correct iteration sequencing, reset behavior, and completion signaling.
