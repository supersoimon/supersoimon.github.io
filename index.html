CORDIC Accelerator

Overview

This project is a basic CORDIC accelerator algorithm, designed to output X and Y coordinates representing the sin and cosine values.

Background

The Coordinate Rotation Digital Computer (CORDIC) algorithm is a technique used to perform operations such as trigonometric calculations without heavy multiplication, as CORDIC relies primarily on addition, subtraction, bit shifting, and lookup tables. The goal of this project is to design a CORDIC accelerator using Verilog. The final design is intended for fabrication through the Tiny Tapeout platform.

Architecture

This ASIC has 4 modules within it; a top level module, a Tiny Tapeout Top Level Module, an angle lookup table, and a rotation calculator. The lookup table and rotation calculator are connected through the top module, which is then fed into the Tiny Tapeout Top Level Module to link it to GPIO outputs.

The algorithm performs 15 "rotations". For each rotation, it adjusts the X and Y coordinates, adding/subtracting them to match the angle's position relative to the target angle. Once all the rotations are complete, the algorithm outputs an X and Y coordinate, being the sine and cosine values.

Hardware Interface

No external hardware is required besides the Tiny Tapeout development board.

Testing

The project can be tested by communicating with the ASIC through its GPIO pins.

  • Set the angle
    • Write the 17-bit signed angle value using the ui_in pins
    • The angle is written in three 8-bit sections
    • uio_in[1:0] selects which byte to write
    • uio_in[2] acts as the write strobe
    • ui_in[7:0] carries the byte being written
  • Start the calculation
    • Set uio_in[3] HIGH to initiate a calculation
  • Wait for completion
    • Set uio_in[6:4] to 110 (channel 6) to read the busy status.
    • A value of 1 means the calculation is in progress
    • A value of 0 means the calculation has finished
  • Read the results
    • Use uio_in[6:4] to select the output channel:
      • 000: X coordinate bits [7:0]
      • 001: X coordinate bits [15:8]
      • 010: X coordinate bit [16]
      • 011: Y coordinate bits [7:0]
      • 100: Y coordinate bits [15:8]
      • 101: Y coordinate bit [16]
      • 110: Busy status
  • Reconstruct the coordinates
    • Combine the three sections of each coordinate to reconstruct the signed 17-bit X and Y values.

Development Log

There were multiple stages of this ASIC. Firstly, I designed the base rotator and angle lookup table Verilog files. I didn't know that I needed a top module at that point, so I tried to get it to work with GitHub Actions and ended up wasting a couple of days trying to fix that. Once I learned that I needed a top module, and I learned how to format everything properly for Tiny Tapeout. After that, I went through and wrote my top modules, and tested everything on testbenches (my rotation didn't really work to well, my lookup table had some major issues). After that, I got it all sorted out with the GitHub actions, wrote my docs, and was ready to go to manufacturing!
