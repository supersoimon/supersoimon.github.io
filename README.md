# Custom Responsive Personal Website
This is a personal website for me to showcase my projects, who I am, and what I like!
# Description
This website is coded in HTML, CSS, and JavaScript. It can adjust to better fit the screen size of mobile devices, and dynamically adjusts image sizing to make the site viewable on all devices. <br>

# Key Features
This project uses JavaScript for automatic smooth adjustable scrolling, based upon the getAnimationFrame() function. It also features a responsive design, with the front page automatically adjusting image position based upon screen size, and with the project boxes flipping their orientation when on mobile.
